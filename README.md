# H3VR2-Sliced
An H3VR2 Decompiler Thats open-source, and has mod integration! 

H3VR2 Sliced is an open-source IL2CPP decompiler for Hot Dogs, Horseshoes & Hand Grenades 2. Built to explore, inspect, and understand the game's underlying code, Sliced aims to make game internals more accessible to developers, modders, and reverse-engineering enthusiasts.
